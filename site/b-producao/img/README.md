# Proveniência das imagens (site/b-producao/img)

Todas derivadas com ffmpeg a partir dos assets reais em `site/assets/` (que não foram modificados):

- `genie-plano.webp`: recorte de `assets/genie.png` (740x1600; área x0 y1092 740x350: abas das etapas + cartão "Ideia e planejamento"), redimensionado para 480 px.
- `genie-thumb.webp`: recorte de `assets/genie.png` (x44 y480 652x366: thumbnail "ISSO MAGOA ELES"), redimensionado para 560 px.
- `genie-tela.webp`: `assets/genie.png` inteiro, redimensionado para 460 px.
- `livro.webp`: `assets/codigopug/livro.png` redimensionado para 360 px (mantém a transparência).
- `codigopug-site.webp`: `assets/codigopug/desktop.jpg` redimensionado para 960 px.
- `codigopug-pagina.webp`: `assets/codigopug/pagina-1.jpg` redimensionado para 420 px.
- `og.jpg`: captura da primeira dobra desta própria página (1440 px de largura), recortada para 1200x630.

Carimbos, réguas de formulário, textura de papel manilha e de aço: desenhados em SVG/CSS no próprio código (sem imagens de banco).
